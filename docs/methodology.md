# Methodology

This project provides an experimental 2D projection of political profiles based on 16 ideological dimensions.

## Current state
- The transformation logic is heuristic.
- The historical and political figure placements are approximate.
- The reference dataset is intended for visualization and comparison, not for academic classification.

## Next steps
- Replace heuristic placements with sourced references.
- Improve transformation calibration.
- Add reproducible OCR extraction benchmarks.
- Add automated tests for scoring consistency.
