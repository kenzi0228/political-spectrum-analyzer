# Advanced personalized interpretation v3

## Objective

The v3 interpretation layer makes the profile reading more personalized, less repetitive, and more analytically useful.

## What changed

- The interpretation now explicitly separates:
  - economic orientation;
  - social-authority orientation;
  - quadrant label;
  - internal tensions;
  - secondary dimensions;
  - closest reference profiles when available.

## Secondary dimensions

The v3 layer can use secondary dimensions such as:

- ecology vs productivism;
- internationalism vs nationalism;
- revolution vs reformism.

These dimensions add nuance without directly replacing the main x/y coordinates.

## Non-repetition rule

Generated interpretation text must pass through a deduplication helper before being displayed. This avoids the repeated analysis blocks that appeared in the Streamlit UI.

## Important limitation

The interpretation remains an analytical model. It is not a scientific diagnosis and should not be presented as a definitive ideological identity.
